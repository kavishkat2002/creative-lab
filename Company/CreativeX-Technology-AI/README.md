# CreativeX Technology AI

Corporate website for CreativeX Technology AI—an AI and software company focused on intelligent automation, data, IoT, cloud platforms, and digital product engineering.

## Website

- Home: services, technology ecosystem, projects, delivery approach, and client feedback
- Services: dropdown navigation, service directory, and six detailed capability pages
- Solutions: industry-specific solution directions
- Projects: filterable AI and software project portfolio
- Case study: Alexa AI Business Agent product concept
- Blog: technical SEO, GEO, structured data, content architecture, performance, and measurement field notes
- Articles: dedicated long-form pages with canonical metadata and TechArticle structured data
- About: company positioning, capabilities, operating contexts, and delivery approach
- Contact: dedicated project enquiry page with a structured email brief
- Experience: branded CreativeX startup and route-loading animation with reduced-motion support

## Technology

- Vinext / React
- TypeScript
- Tailwind CSS
- Lucide icons
- Cloudflare-compatible deployment output

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm run install:ci
npm run dev
```

Build the production version with:

```bash
npm run build
```

## Brand assets

Optimized CreativeX wordmark and AI-android lockup assets are stored in `public/brand/`.

## Content note

Project concepts and demo feedback are clearly identified. Named customer quotations and measured results should only be published after client approval.
